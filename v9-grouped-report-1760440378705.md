### 🔴 Command Injection via ProcessBuilder

**Severity**: CRITICAL | **Tool**: semgrep | **Found in**: 2 files | **Category**: EXISTING_MODIFIED

#### 📋 What is this issue?

User-controlled input is passed directly to ProcessBuilder or Runtime.exec() without validation, allowing command injection attacks.

#### 🎯 Why does it matter?

Attackers can inject malicious commands that execute with application privileges, compromising the entire system.

#### 🔍 Common causes:

- Concatenating user input directly into shell commands
- Not using process argument arrays properly
- Missing input validation and sanitization
- Trusting external data sources without verification

#### ⚠️ Impact if not fixed:

Application uses reflection with user-controlled class names or method names, allowing arbitrary code execution.

#### 🎯 Why does it matter?

        add("org.apache.kafka.common.serialization.StringSerializer");
        add("org.apache.kafka.common.serialization.StringDeserializer");
        add("org.apache.kafka.common.serialization.ByteArraySerializer");
        add("org.apache.kafka.common.serialization.ByteArrayDeserializer");
        // Add other legitimate Kafka classes that need dynamic instantiation
    }});
    
    public static <T> T newInstance(String className, Class<T> expectedType) {
        // Security: Validate class name against whitelist before instantiation
        if (className == null || className.trim().isEmpty()) {
            throw new KafkaException("Class name cannot be null or empty");
        }
        
        // Security: Prevent arbitrary class loading by checking whitelist
        if (!ALLOWED_CLASSES.contains(className)) {
            throw new KafkaException("Class '" + className + "' is not in the allowed classes list");
        }
        
        try {
            // Security: Use context classloader with type checking
            Class<?> clazz = Thread.currentThread().getContextClassLoader().loadClass(className);
            
            // Security: Verify the loaded class matches expected type
            if (!expectedType.isAssignableFrom(clazz)) {
                throw new KafkaException("Class '" + className + "' is not assignable to " + expectedType.getName());
            }
            
            // Security: Only instantiate after all validation passes
            return expectedType.cast(clazz.getDeclaredConstructor().newInstance());
        } catch (ClassNotFoundException e) {
            throw new KafkaException("Cannot find class '" + className + "'", e);
        } catch (Exception e) {
            throw new KafkaException("Cannot instantiate class '" + className + "'", e);
        }
    }
