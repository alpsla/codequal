### Before (Old Architecture)
```
For each issue group:
1. Generate location attachment: group-indentation-locations.json (371K locations)
2. Generate IDE fix file: group-indentation-cursor-fix.json (371K locations + fix pattern)

Total: 134 files (67 groups × 2 files)
```

### After (New Architecture - Bug #33 Fix)
```
For each issue group:
1. Generate IDE fix file: group-indentation-fix.json (ALL locations + fix pattern + metadata)

Total: 68 files (67 groups × 1 file + 1 mapping file)
```
