### Iteration 4 - TRUE AI Call Savings (Session 84 continued)

**Problem Identified:**
- Original implementation called AI for EVERY issue
- `applyPattern` was still making AI calls (just with better prompts)
- `aiCallsSaved` metric was misleading

**Solution Implemented:**
1. **Fix Cache** - Hash(ruleId + codeContext) → reuse identical fixes
2. **Template Transforms** - Simple rules fixed without AI:
   - UnnecessarySemicolon: `};` → `}`
   - MissingOverride: Add `@Override` annotation
   - UseLocaleWithCaseConversions: `.toLowerCase()` → `.toLowerCase(Locale.ROOT)`
   - UnusedImport: Comment out import line
3. **Identical Code Detection** - Same code in story → reuse fix directly
4. **Priority Order**:
   ```
   1. Check FIX CACHE → 0 AI calls
   2. Try TEMPLATE TRANSFORM → 0 AI calls
   3. Check IDENTICAL CODE → 0 AI calls (reuse fix)
   4. Try applyPattern (AI) → 1 AI call
   5. Fall back to full AI → 1 AI call
   ```

**Files Modified:**
- `packages/agents/src/fix-agent/state/pattern-aware-fixer.ts`
  - Added `hashCode()` function
  - Added `applyTemplateTransform()` for simple rules
  - Added `isIdenticalCode()` for direct propagation
  - Added `fixCache` Map with `CachedFix` entries
  - Added `stats` tracking (cacheHits, templateTransforms, directPropagation, aiCalls)
  - Updated `propagatePatternToStory()` with 5-tier priority system
  - Updated `processStoryWithPatterns()` to try all issues without AI first
  - Updated `getPatternStats()` with real tracking
