```java

101: String query = "SELECT * FROM users WHERE id = " + userId;

```

**Suggested Fix:** **Security Critical:** Use PreparedStatement with parameterized queries to prevent SQL injection attacks.

**Why this matters:** SQL injection is OWASP Top 10 vulnerability that can lead to data breach, data loss, or complete system compromise.

**Best practices:**
• Never concatenate user input into SQL queries
• Use parameterized queries (PreparedStatement in Java, ? placeholders)
• Validate and sanitize all inputs
• Apply principle of least privilege for database users
• Consider using an ORM framework like Hibernate for additional protection

**Corrected Code:**

105:     try (ResultSet rs = pstmt.executeQuery()) {

107:     }
108: }
