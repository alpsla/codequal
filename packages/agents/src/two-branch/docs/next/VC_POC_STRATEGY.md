### Phase 3: API Service (1 week) 🔌

**Why API Third?**
1. **Enterprise Upsell**: Custom integrations = $500-$5000/mo
2. **CI/CD Integration**: Block merges automatically
3. **Ecosystem Play**: Enable others to build on us
4. **Defensibility**: API integrations create lock-in

**What to Build:**

**REST API Endpoints:**
```typescript
POST /api/v1/analyze
  - Body: { repoUrl, prNumber }
  - Returns: { decision, issues, score, autoFixCount }
  
GET /api/v1/reports/:id
  - Returns: Full analysis report (JSON)
  
GET /api/v1/teams/:teamId/metrics
  - Returns: Team analytics (for dashboard)
  
POST /api/v1/webhooks
  - GitHub webhook integration
```

**Example Integration: CI/CD Pipeline**
```yaml
# .github/workflows/pr-check.yml
name: CodeQual PR Check
on: pull_request

jobs:
  quality-check:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      - name: Run CodeQual Analysis
        run: |
          curl -X POST https://api.codequal.com/v1/analyze \
            -H "Authorization: Bearer ${{ secrets.CODEQUAL_API_KEY }}" \
            -d '{"repoUrl":"${{ github.repository }}","prNumber":"${{ github.event.pull_request.number }}"}'
      - name: Block if DECLINED
        if: steps.analysis.outputs.decision == 'DECLINED'
        run: exit 1
```

**VC Pitch Story:**
> "We have three tiers: Free GitHub App, $49/mo dashboard for teams, and $500-$5000/mo API access for enterprises who want custom integrations. **The API creates lock-in** - once they integrate CodeQual into their CI/CD pipeline, switching costs are high."

**Time to Build:** 1 week
