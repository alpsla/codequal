# Business Intelligence Reports

This directory contains strategic analysis and business intelligence reports generated by the **Strategic Business Owner agent**.

## Directory Structure

- **`daily-briefs/`** - Daily status briefings and priorities
- **`weekly-reports/`** - Weekly business status reports
- **`strategic-guidance/`** - Strategic priorities and recommendations
- **`investor-preparation/`** - Materials for future investor discussions
- **`decisions/`** - Go/no-go decisions and major strategic choices
- **`metrics/`** - Business metrics tracking (MRR, ARR, CAC, LTV, etc.)
- **`feature-priorities/`** - Feature prioritization analyses
- **`competitive-positioning/`** - Market position vs competitors

## How Reports Are Generated

The Strategic Business Owner agent automatically:
1. Reads all current status files (QUICK_START_NEXT_SESSION.md, planning docs, etc.)
2. Analyzes progress vs plan
3. Coordinates with Market Researcher agent for external intelligence
4. Generates comprehensive, grounded strategic recommendations
5. Saves reports to appropriate subdirectories

## Invoking the Agent

```bash
# Weekly status
"Business owner, weekly status report"

# Feature decisions
"Business owner, what should I prioritize this sprint?"

# Launch decisions
"Should we launch beta next week?"

# Market positioning
"Business owner, how do we compare to GitHub Copilot?"
```
